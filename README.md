# 🎮 JOGitto

Um mini hub de jogos em C desenvolvido como projeto de curso, rodando direto no terminal. Três jogos num só programa, sem frescura.

---

## 📋 Sobre o projeto

O JOGitto reúne três jogos de dois jogadores (ou solo) num menu simples. O projeto foi desenvolvido em dupla como trabalho da disciplina de Introdução à Programação.

---

## 🕹️ Os jogos

**1. Perguntas e Respostas**
Quiz de 5 perguntas de cultura geral. O narrador não tem muita paciência com quem erra.

**2. Cobra na Caixa**
Jogo para dois jogadores. Há 5 caixas escondidas: uma tem um botão (ponto), outra tem uma cobra (derrota) e as demais estão vazias. Os jogadores se revezam abrindo caixas até alguém ganhar ou... levar a cobra.

**3. Gousmas War**
Batalha de criaturas baseada em turnos. Cada jogador controla duas Gousmas, cada uma com nível de fúria inicial 1. Os jogadores podem atacar as criaturas do adversário ou dividir a fúria entre as próprias Gousmas. Quem tiver as duas Gousmas com fúria 6 ou mais, perde.

---

## ⚙️ Como compilar e rodar

Requisitos: GCC instalado.

```bash
gcc jogitto.c -o jogitto
./jogitto
```

No Windows:
```bash
gcc jogitto.c -o jogitto.exe
jogitto.exe
```
